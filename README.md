# IGNIS-SI — online demo

Static build of the IGNIS-SI frontend (NASA Space Apps 2026, *Flame in Freefall*), published with GitHub Pages:
**https://belencorvillo.github.io/ignis-si-web/**

Everything runs in the browser from the bundled PSI catalog: Simulator, Library graph, Applications, Get data and Cite data.
The SI-assisted search of the Library is not available here: it needs the local FastAPI backend and an Ollama model.

Data from NASA Physical Sciences Informatics (PSI). Built for NASA Space Apps 2026 — not an official NASA product.

## Run locally

```bash
npm ci
npm run dev
```
